### Findings

**Repeated continuation stacks every new chain on the same anchor.**
`continueFromResult` always places at `CONTINUATION_OFFSET` from the source
result, so a 1→N fan created only via the keypad lands with coincident endpoints
and looks like one thick curve until the consumer chains are dragged apart.
Misleading symptom: "only one connector appeared after four continuations."
Geometry was fine; positions were identical. Fan verification used a spread
fixture for that reason — not a connector bug.

**`react-native-svg` needs an explicit webpack babel `include`.** The package
ships prebuilt ESM with `.web.js` siblings that `resolve.extensions` picks up,
but without babel it is easy to hit the same class of RN-web transform gaps
gesture-handler already required. Add it next to gesture-handler in
`webpack.config.js` when the dependency becomes load-bearing.
