### Findings

**`Cell` needed an underlay slot, not a child, for the texture.** Putting the SVG as the
first child painted *after* the identity ring and covered the ring's border. Mechanism:
absolute-fill siblings stack in document order; the ring is only a transparent-centre
border, so a later full-rect underlay hides it. Misleading symptom: "identity ring
vanished on results once the texture landed." Fix: render `bandBackground` *before* the
ring inside `Cell`.

**`StyleSheet.absoluteFillObject` is not in this RN type surface.** Prefer
`StyleSheet.absoluteFill` — the Object alias either is absent or untyped under
`react-native` 0.86 / the project's TS config.
